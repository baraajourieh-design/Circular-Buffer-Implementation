# Circular-Buffer-Implementation
المخزن الدائري

تعريفه: مصفوفة تخزن بيانات، ولما توصل لآخرها ترجع للأول (دوران).

عناصره:

· مصفوفة للتخزين
· head: مكان الكتابة
· tail: مكان القراءة
· count: عدد العناصر

الدوال:

· init: 
تجعل head=0 و tail=0 و count=0
· isFull:
ترجع true إذا count == SIZE
· isEmpty:
ترجع true إذا count == 0
· write:
إذا كان المخزن ممتلئاً اطبع "Overflow"، وإلا ضع الحرف عند head وحرك head للخانة التالية وزد count
· read:
إذا كان المخزن فارغاً اطبع "Underflow"، وإلا خذ الحرف من tail وحرك tail للخانة التالية وانقص count

برنامج main:

1. أدخل اسمك
2. أضف "CE-ESY" إليه
3. اكتب كل حرف في المخزن
4. اقرأ كل حرف من المخزن واطبعه
