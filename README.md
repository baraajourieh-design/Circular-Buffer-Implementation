# Circular-Buffer-Implementation
المخزن الدائري

تعريفه: مصفوفة تخزن بيانات، وعندما تصل هذه البيانات لآخر المصفوفة تعود لأولها (دوران).

عناصره:

· مصفوفة للتخزين
· head: مكان الكتابة
· tail: مكان القراءة
· count: عدد العناصر

الدوال:

· init: 
تجعل head=0 و tail=0 و count=0
· isFull:
ترجع true إذا count == SIZE
· isEmpty:
ترجع true إذا count == 0
· write:
إذا كان المخزن ممتلئاً تطبع "Overflow"، وإلا تضع الحرف عند head وتحرك head للخانة التالية وتزيد count
· read:
إذا كان المخزن فارغاً تطبع "Underflow"، وإلا تأخذ الحرف من tail وتحرك tail للخانة التالية وتنقص count

برنامج main:

1. أدخل اسمك
2. أضف "CE-ESY" إليه
3. اكتب كل حرف في المخزن
4. اقرأ كل حرف من المخزن واطبعه
